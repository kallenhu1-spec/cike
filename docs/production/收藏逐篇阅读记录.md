## 两版怎么试

打开项目 artifacts/双材质动作试映.html。选择喝水、合本子、擦叶子；两版共用同一句行动文案，可同时试播一次，也可逐帧查看。每次约 3 秒，之后停住；减少动画时直接显示末帧。还有 10 秒后出现一次的提醒演示，不产生系统通知、不循环。

| 动作 | 文案 | 画面语义 |
| --- | --- | --- |
| 喝水 | 杯子在手边的话，喝一口再继续。 | 抓杯 → 杯沿接近嘴 → 放回杯垫 |
| 合本子 | 告一段落了，把本子合上，给桌面留一点空。 | 打开 → 合盖 → 合拢 |
| 擦叶子 | 离开屏幕半分钟，给手边的一片叶子擦擦灰。 | 布靠近 → 接触叶片 → 收回布 |

仅为关键帧试映，不是流畅视频，也尚未替换桌面默认角色。图像中的细小背景和脸部位移会在切帧时暴露，这是试样要发现的问题，而不是靠持续缩放整张图掩盖。

## 你可以自己学会的检查方式

1. 先把“更可爱”拆成一项：身体更矮胖、眼睛更低、手更短，或材质更软。一次只改一项，否则不知道究竟是哪项有效。
2. 关掉文字看图：能否认出在喝水、收东西、关灯？不能，就改接触关系和道具，别先加表情。
3. 缩到桌面实际显示大小：五官、手和杯子还看得清吗？过密的背景装饰先减掉。
4. 按开始、关键接触、完成三帧检查：同一个角色吗？杯子是否突然变大？书有没有换开合方向？先修静态关键帧，再做动画。
5. 动作结束后放着看十秒：末帧本身是不是一张舒服的常驻场景？如果不是，动画再好也不适合这个产品。

## 正式生产的下一道标准

两套材质各有固定母版和独立版本号，禁止混用。每个动作保存语义标签、起止姿态、对应文案、参考图和生成参数。先独立生成并校正关键姿态，必要时用分层绘制或骨骼绑定保证背景不漂移；图生视频也必须逐帧检查手、道具和脸。视频输出本地播放一次，ended 后替换成末帧静图。失败则退回该动作静态末帧，不用不相关动画填充。
