## 你可以自己学会的检查方式

1. 先把“更可爱”拆成一项：身体更矮胖、眼睛更低、手更短，或材质更软。一次只改一项，否则不知道究竟是哪项有效。
2. 关掉文字看图：能否认出在喝水、收东西、关灯？不能，就改接触关系和道具，别先加表情。
3. 缩到桌面实际显示大小：五官、手和杯子还看得清吗？过密的背景装饰先减掉。
4. 按开始、关键接触、完成三帧检查：同一个角色吗？杯子是否突然变大？书有没有换开合方向？先修静态关键帧，再做动画。
5. 动作结束后放着看十秒：末帧本身是不是一张舒服的常驻场景？如果不是，动画再好也不适合这个产品。

### 本轮可暂存的规划假设（不是笔记事实）

1. 形象生产可能需要拆成“照片主体识别 → 角色候选 → 用户选择母版 → 小动作配图/动作资产”，每一步都可回退，不让一次生成直接覆盖当前形象。
2. “Skill”更适合承载稳定的角色规则、提示词模板、参考图组织、结果检查和重试策略；真正的图像生成仍由 Seedream/豆包等模型 API 执行。是否使用某个现成 skill，需先看它是否支持中国大陆可用的模型和隐私/费用控制。
3. 动作灵活度不能只用生成静态图解决；需要先用同一角色做一个动作技术原型，再比较 GIF、短视频、分层/骨骼和当前关键帧方案。
