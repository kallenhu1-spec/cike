# 0.3.0：画面温暖，动作具体

这次修正的是产品的内容重心。此前偏重“慢慢来、我陪你”，能安慰，但常常不知道接下来可以做什么。参考图有效的地方，是把具体物件、正在做事的形象、有限的一小步放在一起。

## 实际变化

- 重写 56 条七时段内容和 64 条基础内容。当前 136 条中，120 条是行动卡，16 条是纯陪伴；纯陪伴留作内容回退，不再占主导。
- 每张行动卡：具体标题、一个动作、约需时间、明确结束边界、匹配生活场景。例如“给桌角腾一点空 / 把离你最近的一件杂物放回原处 / 约30秒 / 只收这一件，不大扫除”。
- 8 个原创 SVG 场景，各有昼夜版本：杯子、窗边、桌面、纸笔、餐桌、舒展、灯光、音乐。延续本项目原有小纸团的形象与配色；参考图用于理解表达方式，不复用其人物或图案。
- 卡片出现时，桌面小纸团切换为相应生活场景；收起时回到原形象。用户自己换过的图片优先保留，不强行覆盖。
- 默认 30 秒收起。可点“留在桌边”，卡片会停留且自动出句暂停，直到收起或恢复自动收起；不是倒计时，不要求点击完成，也不记录执行成绩。
- 保留时间、作息、偏好、近期历史、禁忌、静默和每天最多4次的规则。不增加消息频率来追求行动感。
- 新版 AI 提示词要求至少80条具体小动作、最多20条纯陪伴；附结构化 action 字段。旧纯文本词库继续兼容，不自动修改用户导入的私人内容。

## 文案标准

|过去|现在|
|---|---|
|“给下午留一点空白”|“把离你最近的一件杂物放回原处。只收这一件。”|
|“明天的事情，明天再见面”|“写下明天第一件要做的小事，然后合上本子。”|
|“如果愿意，看看窗外”|“看向窗外，找出两种不同的颜色。看到就好。”|
|“给自己一点松软”|“双手离开键盘，张开手指，再轻轻放松。”|

一条只邀请一个小动作。时间是大致用时，不是必须达标的要求；不暗示心理或健康效果。不说“做不到也没关系”来填充每一句，改用清楚的小边界降低开始成本。未确定的事实仍保留条件：“还没吃饭的话”“准备休息的话”。

## 怎么体验

右键小纸团 → 小小的偏好 → “看看这一刻”。先选早晨，再试午后、睡前。桌面会出现动作标题与小场景。你不需要完成或回复，可以直接收起。

如果已有个人词库仍显得抽象，可生成新版提示词，重新制作并导入；原库保持原样，避免擅自改写用户内容。

## 开发与测试

- `npm test`：核心规则与内容结构测试。
- `npm run test:smoke`：真实 Electron 七时段预览、设置、导入与重启测试。
- `npm run test:visual`：8个场景昼夜版本实际解码、卡片停留/自动收起、最长文案、窄设置窗口、自定义形象保留。
- `npm run build:scenes`：从原始小纸团 SVG 和原创场景构图重新生成8组昼夜SVG。

## 可维护的布局约定

- 桌面透明窗为340×560逻辑像素。顶部透明空间用于容纳最长昵称和导入文案，空白鼠标穿透；可见内容靠下对齐。
- 气泡左边距16px，宽308px，距底208px；内边距16×18px。动作标题20px，正文13px，结束边界11px。
- 场景原图600×320，按308px宽等比缩放，contain，不裁切。无卡片时恢复170px小纸团。
- 默认设置窗口690×820，最小540px宽；540px时预览图文上下排列，690px时左右排列。移动端不在本桌面应用的范围内。
- 图片是本地真实SVG资源。场景缺失时回退默认形象，文字继续可见。没有远程图片依赖。

## 布局相关状态

|状态|画面与行为|
|---|---|
|待机|原形象轻呼吸，透明空白可穿透|
|行动出现|动作气泡与生活场景；约30秒收起|
|留在桌边|保持画面，停止自动替换，可手动恢复或收起|
|纯陪伴 / 旧词库|只显示正文与默认形象，不捏造动作|
|自定义形象|保留用户图片，仍展示行动文字|
|图片失败|回退原形象，卡片内容可继续阅读|
|候选为空|保持安静，不绕过屏蔽或禁忌|
|关闭主动出现 / 锁屏|隐藏气泡并停止停留状态，照原规则恢复|

## 素材映射

`water.svg`→饮水/杯子；`window.svg`→窗边/植物；`desk.svg`→桌面/物件；`note.svg`→书写/阅读；`meal.svg`→餐食；`stretch.svg`→放松手与身体姿势；`lamp.svg`→灯光；`music.svg`→音乐/耳机。具体文字决定使用哪张图，不以时段硬套不相干画面。
