# 0.2.0：让此刻跟着一天生活

当前已升级至0.3.0，时段规则继续沿用，文案已改为以具体小动作为主并加入生活插画，详见[行动陪伴说明](行动陪伴说明.md)。以下为0.2的历史说明。

从参考图中吸收的是生活场景：早晨的小期待、简单的一餐、下午歇一下、给环境留点空白、睡前轻轻收尾。没有复制饮食配方、任务清单、倒计时或要求用户自律的语气。

## 如何体验

右键小纸团 → 小小的偏好。页面顶部“听听这一刻”可选择早晨、上午、午饭、午后、傍晚、睡前、深夜。先保存自己的称呼、喜好、作息和语气，再试听。无需改变系统时间；试听不写近期历史、不占每日次数、不影响下次自动出现。试听仍避开被屏蔽的句子与禁忌词。

默认仍每天最多 4 句，并不会七个场景各说一遍。深夜属于可用内容场景，不意味着无视你的安静时段。日常不需要任何点击。

## 七个场景

|本地时间默认范围|场景|例句|
|---|---|---|
|06:00–09:00|慢慢醒来|一天可以从喜欢的杯子开始，不必急着进入状态。|
|09:00–11:30|上午的小空隙|事情可以一件件来，不必同时抱住所有。|
|11:30–14:00|午饭前后|午饭可以简单一点，有喜欢的味道就好。|
|14:00–17:30|午后的松口气|如果想歇一下，给下午留一个小小的停顿。|
|17:30–20:00|傍晚的日常|如果今天可以收工了，就把剩下的事先合上。|
|20:00–23:00|准备收尾|今天没必要写成总结，普通地结束也很好。|
|23:00–06:00|夜里轻一点|夜里我会更安静，你不用回应。|

个人作息优先修正两个场景：填写 `11:00–02:00` 后，11:00–12:30 属于起床场景，01:00–02:00 属于收尾场景。格式支持横线、短横线和“至”；无法识别的文字不会报错或猜测，会明确提示按本地时间工作。作息必须有 4–22 小时的清醒跨度，否则回退本地时钟。安静时间始终由单独的设置决定。

## 怎样选一句话

1. 先检查能否说话：主动开关、安静时段、锁屏、解锁延迟、闲置 5 分钟、最小间隔、每日上限。
2. 将非安静时间均分为每日额度个时间段，每段最多说一次。默认 08:00–23:00 / 4 句，即 08:00–11:45、11:45–15:30、15:30–19:15、19:15–23:00。错过的段不补发。该时间段机会跨重启保留。
3. 按场景与星期筛选。周末专属句只在周末出现，周一句只在周一出现；不推测节假日或是否放假。
4. 排除近期 20 条和屏蔽项；检查真正展示的语气版本是否含禁忌词。
5. 优先匹配已保存的喜好；刚聊过同主题则降低其概率，避免反复提喝水或热茶。
6. 有匹配的专属词库优先用专属；没有匹配才回到本地内容。没有安全候选则保持安静。

这是本地规则和内容选取，不是持续联网的生成模型。它知道本地时间、你主动填写的作息与偏好、自己说过什么；不知道你实际吃没吃饭、做了多少工作或心情如何，所以相关话语都保留“如果”。

## 内容与兼容性

保留原有 80 条，新增 `assets/moments.json` 56 条，共 136 条基础记录。新内容每条另有俏皮和简短版本，设置语气后立即生效。原 80 条作为回退内容，没有额外语气版本。

新版 AI 提示词仍生成 100 条，新增可选字段：

```json
{
  "id": "p001",
  "text": "午饭可以简单一点，有喜欢的味道就好。",
  "period": "any",
  "scenes": ["lunch"],
  "tags": ["午饭"],
  "topic": "吃饭",
  "weekdays": [0, 6],
  "variants": {
    "带一点俏皮": "午饭不用拿满分，好吃就很厉害。",
    "简短留白": "午饭里，留一点喜欢。"
  }
}
```

上例只在周末午间出现；平日也要用就省略 weekdays。scenes、topic、weekdays、variants 均可省略，旧四时段 JSON 继续可用。新增字段会校验并存储，重启不丢失。结构校验不替代文案人工审稿。

旧昵称、图片、最近历史、屏蔽项、首次相遇与位置继续保留；旧记忆文件缺少时间段字段时补默认值，不重置档案。自动台词会写记忆，主动试听不写；最近一次试听的句子仍可通过右键永久屏蔽。
