# 小小配音室 · 0.7.0

这是基于 0.6.1 的本机配音功能，角色名称统一为“小纸团”。入口：右键小纸团 → 小小配音室；也可从“小小的偏好”打开。

## 和孩子一起使用

1. 家长与孩子一起确认愿意参与。可以直接为选中的台词录音，也可以导入已有录音。录音和导入文件只在本机处理。
2. 想让 AI 延展其他台词，先录一段 5–20 秒的声音样本。用自然说话的声音，尽量没有音乐、其他人或风扇声。默认示例可替换，文字必须和录音实际内容一致；已有样本的文字可单独修改并保存。
3. 在台词本选一句，点“用样本 AI 配这句”。也可一次排队生成前 5 条尚无录音的台词。已有录音不会被 AI 批量覆盖；生成可停止，单句最长等 4 分钟。
4. 每句先试听，再点“用这版声音”。亲录和 AI 配音均区分来源、均先待试听。生成不是启用；听到吞字、含糊或不像时，删除这句后重试。样本重录只影响之后生成的内容。
5. 行动卡出现时，已启用且文字精确匹配的配音会自动播放。没有配音则只显示文字，不临时联网，也不偷偷换成系统声。卡片上的称呼前缀不额外合成，配音对应正文；语气变更后要为新文字另配音。试读句标为“仅试听”，不自动出现在提醒里。
6. 完成行动 → 举手 → 点手掌后播放约 0.3 秒的原创合成拍掌声；已启用“耶，击掌！这件事完成啦。”时接着说这句。只举手未击中不会响，安静时不显示击掌按钮。

音量、声音总开关、击掌音效可分别调整。收起卡片、换句、锁屏或睡眠会停止当前声音。关闭配音室释放录音设备并取消正在生成的任务。系统拒绝麦克风时可使用导入，或到系统设置 → 隐私与安全性 → 麦克风允许“此刻”后重开。实际麦克风硬件需家长首次录音时验证，自动测试没有采集环境声音。

## 本机 AI 安装与启动

本轮这台 Apple Silicon Mac 已安装并实际运行 Qwen3-TTS 0.6B Base（MLX Audio 0.3.1）。引擎和模型位于项目 `.private/voice-runtime/`，独立 Python 在 `.private/python/`，总计约 3 GB；不纳入源码快照和 Git。仅初次安装下载公开模型，生成时强制离线并关闭模型库遥测，没有云端 API 或上传入口。

开发态：`npm start`。最终本机测试应用：`dist/0.7.0/mac-arm64/此刻.app`。应用旁的 `dist/0.7.0/voice-runtime` 是指向已安装引擎的本机链接；不要单独搬走 `.app` 后假定 AI 仍能找到。直接复制应用到另一台 Mac 只能使用亲录/导入与击掌音效，需另行安装 AI 引擎。

首次在新的 Apple Silicon Mac 准备环境，需要 Python 环境管理工具 uv、网络和至少约 4 GB 可用磁盘空间，在项目目录运行：

```sh
npm run voice:setup
npm start
```

可用 `CIKE_VOICE_RUNTIME` 指定引擎目录。打包应用依次查找该环境变量、应用 userData 下的 `voice-runtime`、本地版本目录旁的 `voice-runtime`。引擎安装不代表声音效果通过验收。Windows / Intel Mac 的本机 AI 路线未实现；已有录音播放不依赖 AI 引擎。

## 数据与删除

声音资料单独保存在 Electron userData 的 `voices/voice.json`，包含样本文字、原声音频、台词音频、来源、启用状态和设置。采用临时文件与原子替换，目录 0700 / 文件 0600；不是加密存储。现有“导出本地记忆”不包含录音。

可删除单句、删除样本，或在原生确认框中清除全部声音资料。删除样本不删除已生成台词；“清空全部记忆”也会清除当前声音资料。生成临时文件在完成/失败/取消后清理，进程异常退出可能留下临时目录，下一次启动会清理。模型本身不会随清除个人声音资料删除。不导出、公开分享或上传孩子声音。

## 验证与边界

- 单元测试校验 WAV、静音、时长、损坏文件、精确台词匹配、待审播放隔离、重启持久化、设置与删除。
- Electron 回归使用隔离的资料目录和合成测试音频；验证录音开始/停止、设备轨道释放、拒绝麦克风路径、试听、启用、静音、击掌、窄屏、重启与删除。没有录制真实麦克风。
- 真实本机模型使用 macOS Tingting 合成声音作参考，生成新的击掌台词，验证离线推理和待审保存；不能据此声称女儿的声线、情感、发音或相似度通过验收。
- 第一轮真实推理约 36 秒，输出 3.36 秒音频；只是这台机器的单次结果，不是性能承诺。详细结果在 `artifacts/0.7.0-AI链路测试.json`。生成可能吞字、重复或提前停止，需要逐句听。
- 60 MB 本机配音存储上限；单条 0.2–30 秒；样本 5–20 秒；导入文件上限 15 MB，浏览器解码为单声道 PCM WAV。不会自动识别实际说出的文字，请人工核对。
- 本机应用未签名/公证、未在其他机器或 Windows 验证。无提交、推送或发布。当前评审状态：待家长和孩子试听。

## 查阅的技术来源（2026-09-22）

- [MLX Audio 官方项目的语音克隆说明](https://github.com/Blaizzy/mlx-audio/blob/main/docs/guides/voice-cloning.md)：实际读取 Qwen3-TTS Base 的样本音频+文字用法及样本准备建议。
- [MLX Audio 生成实现](https://github.com/Blaizzy/mlx-audio/blob/main/mlx_audio/tts/generate.py)：核对参数与音频输出；又核对本机安装版本的 Qwen3 实现。文档与实际版本并非永远一致，安装版本固定并有真实输出。
- [Qwen3-TTS 技术报告](https://arxiv.org/abs/2601.15621)：仅读取摘要的克隆能力范围，不把论文指标当成孩子声音的实测结果。
- [Electron session 权限](https://www.electronjs.org/docs/latest/api/session)、[麦克风授权](https://github.com/electron/electron/blob/main/docs/api/system-preferences.md)：只允许配音室顶层页面请求音频，摄像头与其他窗口拒绝；打包加入麦克风用途说明。

本轮未采用第三方云声音服务，也不把个别服务的儿童声音条款推广为所有本机工具的限制。

## 0.7.2 声音控制补充
右键小纸团 → 播放声音，可快捷切换自动台词和击掌音效；配音室仍可调整音量。台词本勾选“这句不配音，只显示文字”后，自动播放和批量补配均跳过它，原音频保留且可手动试听。取消勾选即可恢复已启用的配音。覆盖统计只计算当前语气日常句，排除仅试听句；换语气后文字变化需要对应配音。录样本本身不启动批量生成；本机AI使用参考样本，不将击掌亲录自动拼接成第二个参考样本。
