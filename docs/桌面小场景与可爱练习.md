# 此刻 0.4：住在桌面的小场景

## 怎么体验

打开 `dist/0.4.0/mac-arm64/此刻.app`。右键小场景 → **可爱实验室**；也可从“小小的偏好”进入。

- 平时：常驻场景，不必等提醒出现。起床喝水、上午写字、午饭用餐、午后看窗外、傍晚收桌面、夜里开小灯。按已保存作息和本地时间，每分钟刷新；收起卡片也保留场景。
- 点一下场景：出现一张适合现在的提醒；再次点击换一张。回车和空格也可使用。每轮避开已看过的候选，耗尽后重新开始；如果只有一条安全且合适的内容，允许重复。手动取卡不占自动提醒额度，仍过滤禁忌、屏蔽项和不合时段的内容。
- 拖动超过 6 px：移动场景，不冒出提醒。右键：偏好、形象、实验室、安静和退出。
- 到时间：沿用自动提醒规则，默认最多四次/天、至少相隔 90 分钟、夜间 23–8 时安静；次数分散到全天，锁屏、电脑闲置和刚唤醒时不催促。主动点击是用户请求，所以安静时段仍可取卡。
- 内容 30 秒收起；“留在桌边”可固定，期间不被自动卡覆盖。

当前“更多提醒”来自 136 条内置内容或用户导入的 100 条专属内容，按时间、偏好挑选；不是每次联网调用 AI。五字段 → 外部 AI 一次生成 → 校验导入 → 本地离线使用的路径保留。场景是原创 SVG 插图，当前没有角色骨骼动画、实时天气、读屏或情绪识别。

## 不用先学术语，先练习比较

实验室中的三种造型是设计起点，不是“可爱程度”排行榜：

| 起点 | 可观察的变化 | 可以用来表达的感觉 |
| --- | --- | --- |
| 小纸团 | 不规则轮廓、折痕、点点眼 | 笨拙、轻盈、有手作感 |
| 圆团子 | 连续圆轮廓、脸偏下、眼稍大 | 饱满、软、像能捧在手里 |
| 软豆子 | 左右不对称、眯眼 | 松弛、有一点自己的脾气 |

三个预设同时改了多个因素，只用来选起点。真正学习时用 A/B：

1. 选一个喜欢的预设，点“把右边设为对照”。A 固定不动。
2. 只改“五官位置”。看额头留白、稚拙感是否更合心意，然后调回去确认。不要同时改眼睛和身体。
3. 只改“眼睛大小”。放大的角色好看，不代表 308 px 的桌面场景里也清楚；比较下面实际尺寸的场景。弯眼时该项改变弯眼的宽度。
4. 再试表情：点点眼、开心、眯眼。需要更活泼还是更安静，由你判断，不由一个“可爱分数”决定。
5. 点“把这个用到桌面”，所有内置场景中的角色一起变化。参数本地保存，重启有效；“恢复原来的小纸团”随时回到初版。

应用内置角色会切回内置形象；如果之前用了自己的图片，需要从右键菜单重新选择。未点击应用的尝试不会改桌面；退出实验室会丢弃这些未应用的尝试。

### 让模糊反馈变成能执行的反馈

- “不够可爱” → “我更喜欢 B 的圆轮廓，但保留 A 的小眼睛。”
- “想软一点” → “减少身体尖角，脸下移一点，颜色先不动。”
- “没生命感” → “它拿着杯子时，手要真的贴着杯子；表情像正准备喝一口。”
- “画面挺好，但不想行动” → “让图和文字是同一个动作：它捧杯子，文字只说‘拿起手边的杯子，喝两口’。”

可以复制给设计师或 AI 的改图说明：

> 保持此刻的叶芽、奶油色和原场景不变。只把身体改得更圆润，五官下移一点，保留小眼睛。输出原版/改版对照，并缩到桌面实际尺寸检查。不要同时增加装饰。提醒画面里角色要正在做文案对应的动作；一次只给一个能马上开始的小步骤。

### 从参考图学到的东西

本轮重新查看了参考文件 `Weixin Image_20260920234810_810_2.jpg`（吃饭）与 `Weixin Image_20260920234820_821_2.jpg`（洗漱）：小脸、圆轮廓、有限的柔和配色、日常物件、明确动作。图中文字是参考材料，不作为医疗或生活指令执行。

对《此刻》最有用的是“日常物件 + 角色正在行动 + 一句话说清第一步”。只堆粉色、爱心和安慰句，不能替代这个关系。当前实验室解决轮廓/五官的判断练习；笔触质感和细致动作仍可继续迭代，不能声称已经复刻参考图的手绘质感。
