# 此刻 0.8.0 · 由你定制

电脑单机体验版，适用于 Apple Silicon Mac。无需账号或 API Key；日常陪伴、图片、小动作和亲录配音在本机使用。当前包未签名公证，未完成其他电脑、Intel Mac 或 Windows 安装验收。

## 打开与日常使用

退出旧版，再打开同包的“此刻.app”。右键小纸团 → 设置与定制，在左上核对0.8.0。点小纸团获得一个小动作，拖动移动位置；完成后可击掌。退出用右键“退出此刻”。“暂停自动提醒”持续有效，重新勾回后才恢复；主动点击仍可使用。

## 自己配置

1. 形象与衣橱：打开现有小衣橱，或选择PNG/JPG/WebP图片（5MB以内）。预览后点应用。图片保留原比例；透明PNG更容易融入桌面。自选图片是静态形象，不会自动换装或生成动画。
2. 我的小动作：选择内置内容修改，或新建。填写提示语、时段、用时与收尾语；选内置场景/单次动作，或自己的静态配图。保存后点“在桌面试一下”。取消“启用”后保存即停用；筛选“已停用”可以重新启用。
3. 给这句话配音：从小动作编辑页进入会选中对应台词。录音或导入后先试听，再启用；也可以选择不配音。文案修改后需要新文案对应的声音；旧录音保留为仅试听条目，不会自动配给新文字。声音属于本人或已获同意；儿童声音需要监护人同意且孩子愿意参与。
4. 陪伴与数据：调整称呼、喜好、语气、作息、提醒次数与安静时段。导出配置可备份偏好、形象、小动作和历史；不含声音。导入覆盖前会自动备份当前配置到companion.before-restore.json。

## 本机保存与AI边界

Mac资料目录通常为 `~/Library/Application Support/cike-companion/`。声音独立在 `voices/voice.json`；并非加密文件。分享应用包不会把此目录一起分享，不要把自己的备份或声音目录作为公开安装附件。

AI配音需要额外本地引擎，当前体验包不含模型。未安装仍可录音、导入和播放。本机开发用户的引擎准备方式见项目 `docs/小小配音室.md`；没有一键引擎安装器，不能把本机已装好的效果当作其他电脑已具备。

手机配置、云端同步、上传图片自动生成动作未提供。首次系统拦截请按macOS的应用安全提示处理，不建议关闭整机安全检查。此包应先由受邀体验者验证安装，不作为已公证正式发行包。
