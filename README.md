## 运行

Node.js 22+，首次安装需要网络下载 Electron。日常运行完全离线。

```bash
npm install
npm test
npm start
```

拖动小纸团移动位置；右键打开菜单；回车 / 空格也可打开。托盘 / 菜单栏可找回设置。窗口的透明空白区域会让鼠标穿过；小纸团可操作。macOS Control+点击也可触发系统右键行为，若环境不支持请使用双指点按或托盘。

默认启动 12 秒后尝试问候，间隔至少 90 分钟，每天最多 4 条，并分散在一天的四段非安静时间中，23:00–08:00 安静，电脑闲置 5 分钟后不说话。深夜首次打开不出现气泡是正常行为；右键“听一句”可主动预览，预览不计入当日条数、不写历史，允许主动绕过静默和上限。气泡 30 秒后淡出；点击“留在桌边”可保持卡片并暂停自动出句，不需要回复。若所有合适内容都被过滤，会保持沉默。

“只安静待着”持续生效，直到重新开启；不会第二天悄悄恢复。隐藏气泡不关闭应用，退出在右键菜单里。没有开机自动启动或系统通知。

## 个性化

右键 → 小小的偏好 → 五字段可选 → 保存 → 生成提示词 → 复制给自己选择的 AI → 检查并保存为 100 条 JSON → 导入。应用不联网调用模型、不持有 API 密钥。档案字段只有被主动复制分享后才离开电脑。导入发生错误时保留原库。恢复内置按钮只移除专属内容；清空全部记忆需原生确认框。

上传图片限制 5MB，支持 PNG/JPEG/WebP，经原生解码转为 360px PNG 存本地；透明 PNG 效果最佳。图片按正方形缩放；非方图建议事先裁成正方形。引用图片不作为可再分发资源，本项目形象独立绘制。

## 本地数据

调用 Electron `app.getPath('userData')` 获取实际位置；macOS 开发态通常为 `~/Library/Application Support/cike-companion/companion.json`，应用名称变化后路径可能不同。设置中可导出，无需手工找路径。存储包括五项偏好、频率、首次见面、近期句子 ID、屏蔽 ID、自定义库、形象和窗口位置。没有截图、按键、访问网址、账号或遥测。

写入使用临时文件与重命名；损坏 JSON 留 `.corrupt-时间戳` 备份。备份可能含旧偏好；设置清空会清除当前状态及该文件的损坏备份。导出文件也不会被清空操作删除。没有云同步和导入备份入口。
